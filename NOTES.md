# Teaching notes

- Prefer quizzes, retrieval questions, and conceptual checks over pseudocode-writing and inventing test names.
- Prefer learning a less-familiar implementation language when its mechanics reinforce the architecture lesson. TypeScript is the chosen language for the first executable slice; introduce only the language features needed by each lesson.
- The learner began Lesson 18 with no familiarity with TypeScript or discriminated unions. Teach TypeScript from first principles, compare unfamiliar syntax with Python when useful, and do not treat one successful exercise as general TypeScript fluency.
