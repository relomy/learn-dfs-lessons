Team context lookup

Look up a team's game context without hiding an absent match.

Contract

type TeamContextLookup =
  | { readonly kind: "found"; readonly context: TeamGameContext }
  | { readonly kind: "missing"; readonly team: string };

Function

findTeamGameContext(
  team: string,
  contexts: readonly TeamGameContext[],
): TeamContextLookup

Caller pattern

const lookup = findTeamGameContext(candidate.team, contexts);

if (lookup.kind === "found") {
  use(lookup.context);
} else {
  reportMissing(lookup.team);
}

A missing lookup means no usable context was supplied for that team. It is not a pick'em and must not become a zero-valued context.
