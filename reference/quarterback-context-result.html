Quarterback context result

Attach matched team game context to a candidate without changing the candidate itself.

Outcomes

context-ready
  candidate: QuarterbackCandidate
  gameContext: TeamGameContext

missing-game-context
  candidate: QuarterbackCandidate
  team: string

Flow

candidate.team
  → findTeamGameContext(candidate.team, contexts)
  → QuarterbackContextResult

Boundary

Attaching context says which context belongs to a quarterback. It does not say whether that context is favorable, and it does not change the evaluator yet.
