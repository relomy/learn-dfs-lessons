What changes now

Require team: string on normalized input and on the assembled candidate. Update each complete input fixture. Copy the value in assembleQuarterbackCandidate.

What does not change

The evaluator has no team-dependent rule yet, so its input and output stay unchanged. Do not add provider-specific team names to domain types.
