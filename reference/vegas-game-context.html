Vegas game context

Turn a game total and a signed home-team spread into one context for each team.

Input

away team: BUF
home team: HOU
game total: 48
home spread: -3

A negative home spread means the home team is favored. A game total is the expected combined score.

Formula

home implied total = game total / 2 - home spread / 2
away implied total = game total / 2 + home spread / 2

For the example above, Houston has 25.5 implied points and Buffalo has 22.5. The two implied totals must add back up to 48.

Checks

  • A negative home spread gives the home team the larger implied total.
  • A zero spread gives both teams half the game total.
  • The two implied totals add up to the game total.

What it means for QB evaluation

Game total describes the scoring environment. Implied team total describes how much of that scoring the QB's team is expected to supply. Both are context signals, not a complete player ranking.
