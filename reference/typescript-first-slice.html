TypeScript first slice

Commands, files, and type patterns for the first executable quarterback path.

Commands

npm test          # compile and run the tests
npm start         # compile and run the in-memory example
npm run typecheck # check types without emitting JavaScript

Path through the code

main.ts
  → application.ts
      → assembly.ts
      → evaluation.ts
  → presentation.ts

Discriminated union

type AssemblyResult =
  | { kind: "ready"; candidate: QuarterbackCandidate }
  | { kind: "needs-review"; reason: string }
  | { kind: "rejected"; reason: string };

Check kind before reading fields that belong to one variant. TypeScript then narrows the value to that variant.

Syntax used in policy tests

const input: NormalizedQuarterbackInput = {
  ...baseInput,
  passingAttempts: { kind: "known", value: 7 },
};
  • : gives a variable or property its expected type.
  • ...baseInput copies properties into a new object.
  • A later property replaces a copied property with the same name.
  • "a" | "b" permits exactly those two string values.

Change test

  • Scoring rule changes belong in evaluation.ts.
  • Routing changes belong in application.ts.
  • CLI wording changes belong in presentation.ts.
  • Provider parsing does not exist in this slice yet.
