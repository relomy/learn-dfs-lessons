# Evaluation contracts make assumptions explicit

The learner understands that an evaluation policy should receive domain-owned inputs and return an explicit evaluation result or “not evaluable” outcome. They distinguish missing data from a zero value and understand that the evaluation contract is separate from a provider’s raw DTO or file format.

## Evidence

The learner correctly answered the evaluation-contract quiz and identified that the DTO reference was only tangential until the distinction between source DTOs and application-owned evaluation inputs was made explicit.
