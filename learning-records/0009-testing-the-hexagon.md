# Tests belong at the boundary they verify

The learner understands that domain tests verify domain rules, adapter tests verify provider translation, use-case tests can use a fake port, and integration tests verify real components and wiring together. They also understand that integration tests should use representative checked-in fixtures rather than live external services.

## Evidence

The learner correctly classified test responsibilities in a scenario quiz and explained that an integration test should prove collaboration between the real source adapter, domain model, use case, and composition root.
