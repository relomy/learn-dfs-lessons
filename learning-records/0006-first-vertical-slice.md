# A vertical slice proves one narrow path

The learner understands that the first executable slice should trace one raw source row through translation into a valid `Player` and `SlatePlayer`, or stop with a rejection. They can identify behavior that should remain outside this slice, such as selecting and sorting quarterbacks, and prefer quizzes and conceptual checks over writing pseudocode or test names.

## Evidence

The learner distinguished adapter validation from domain invariants, proposed meaningful test ideas, and recognized that sorting and QB selection belong to a later use case.
