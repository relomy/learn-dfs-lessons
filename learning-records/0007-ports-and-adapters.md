# Ports express purpose and adapters satisfy it

The learner understands that a port describes an application capability or need, while an adapter translates a technology-specific interface into that contract. They understand that the application should depend on the port, that multiple adapters can satisfy one port, and that test adapters can replace external systems.

## Evidence

The learner scored the ports-and-adapters retrieval quiz correctly and articulated the dependency direction from the application-owned contract to external adapter implementations.
