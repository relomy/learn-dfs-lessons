Lesson 22 · DFS analytics architecture

Turn Vegas lines into team context

Derive a game total and an implied team total for each offense from one Vegas line.

The data we need

A game total captures the expected combined scoring environment. A point spread divides that expectation between the two teams. For the first exercise, work with this captured line rather than choosing a live provider yet:

const line = {
  awayTeam: "BUF",
  homeTeam: "HOU",
  gameTotal: 48,
  homeSpread: -3,
};

A negative home spread means Houston is favored by three points.

Prediction before code:
Which team should receive the larger implied total, and what two numbers should the function return?

Derive both team contexts

Create src/vegas.ts. Keep the source-specific format outside this module. Its input is the small domain-shaped line we need for the calculation.

export interface VegasGameLine {
  readonly awayTeam: string;
  readonly homeTeam: string;
  readonly gameTotal: number;
  readonly homeSpread: number;
}

export interface TeamGameContext {
  readonly team: string;
  readonly opponent: string;
  readonly gameTotal: number;
  readonly impliedTeamTotal: number;
}

Return the away-team context first, then the home-team context. A fixed order makes tests simple.

Red: describe the home-favorite case

Create test/vegas.test.ts and write this test before the function exists:

import assert from "node:assert/strict";
import test from "node:test";

import { deriveTeamContexts } from "../src/vegas.js";

test("A home favorite receives the larger implied total", () => {
  assert.deepEqual(
    deriveTeamContexts({
      awayTeam: "BUF",
      homeTeam: "HOU",
      gameTotal: 48,
      homeSpread: -3,
    }),
    [
      {
        team: "BUF",
        opponent: "HOU",
        gameTotal: 48,
        impliedTeamTotal: 22.5,
      },
      {
        team: "HOU",
        opponent: "BUF",
        gameTotal: 48,
        impliedTeamTotal: 25.5,
      },
    ],
  );
});

Run npm test. TypeScript should fail because the module has not been created. That is useful red feedback. The test has named the contract you need to build.

Green: use the line equations

Add deriveTeamContexts in src/vegas.ts. Use these equations:

home implied total = game total / 2 - home spread / 2
away implied total = game total / 2 + home spread / 2

With a home spread of -3, Houston receives three points more than an even split and Buffalo receives three fewer.

Strengthen the boundary

Add two more tests:

  1. A pick'em game, with homeSpread: 0, gives each team half the total.
  2. The two implied totals add up to the game total.

The second test protects the relationship between the values. It is stronger than checking a second arbitrary example.

What this does and does not say

A high game total and a high implied team total describe a favorable offensive environment. They do not predict passing production by themselves. Rushing touchdowns, defense, and other players can produce points too.

The next integration will attach this context to a quarterback. That will require team and matchup information on the candidate, plus a real source adapter that translates provider data into VegasGameLine.

Explain the result

  1. Why does a negative home spread increase the home team's implied total?
  2. Why must the two implied totals add back up to the game total?
  3. Why is a favorable scoring environment useful context but not a complete QB ranking?

Done when

Your three Vegas tests pass, type checking passes, and you can explain why the derived team totals preserve the original game total.

Ask about the spread sign before changing the formula. A reversed sign produces plausible-looking numbers for the wrong team.
