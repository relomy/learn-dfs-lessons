Lesson 10 · DFS analytics architecture

Design the first use case

Keep source translation separate from application policy.

The idea

A use case coordinates an application goal. It should speak in domain terms, request data through ports, and apply rules that express what the application is trying to accomplish. It should not know CSV headers, file paths, or DraftKings status codes.

Responsibility test:
Ask whether the rule would still exist if DraftKings disappeared. If yes, it probably belongs in the application or domain rather than the adapter.

First-slice responsibilities

  • Adapter: read rows, translate values, and report source-data problems.
  • Use case: request slate players, apply the first-slice selection policy, and return an application result.
  • Domain: protect valid values and expose meaningful concepts.

The existing prototype combines source loading with “available quarterbacks ordered by salary.” Lesson 10 asks you to decide which parts are source preparation and which parts are application policy.
